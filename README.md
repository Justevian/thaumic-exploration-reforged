# Thaumic Exploration: Reforged

**Русский** · [English](README.en.md)

Неофициальный порт **Thaumic Exploration 1.1-53** с Minecraft 1.7.10 на **Minecraft 26.3** для [Thaumcraft 4: Reforged](https://github.com/notlikethiss/thaumcraft-4-reforged). Аддон добавляет свою вкладку с 31 исследованием в Таумономиконе. Доступны русский и английский языки.

## Что добавляет мод

- **Эссенция и алхимия.** Связанные банки, банка-утилизатор, вечная и огненная урны, тигель и жаровня душ.
- **Автоматизация.** Связанные сундуки с общим инвентарём для големов и воронок, автоматический сортировщик и репликатор.
- **Магическое снаряжение.** Янтарные и трансмутационные стержни, посох некроманта, наконечники странника и механика, сапоги метеора и кометы, кольца и зачарования.
- **Исследования.** Парящие свечи для стабилизации наполнения и мозговой резервуар, который извлекает фрагменты знаний из книг.

**Масштаб Таумономикона.** Наведите курсор на карту исследований и прокрутите колёсико. Начальный масштаб 80%, диапазон от 40% до 160%.

## Установка

1. Создайте профиль **Minecraft 26.3** с **NeoForge 26.3.0.102**.
2. Скачайте JAR из [релиза для 26.3](https://github.com/Justevian/thaumic-exploration-reforged/releases/tag/v0.1.19-alpha%2B26.3).
3. Поместите его в папку `mods` вместе с **Thaumcraft 4: Reforged 1.1.3 для 26.3** и **TerraBlender 26.3-26.3.0.0.9**.

[Скачать Thaumcraft 4: Reforged](https://github.com/notlikethiss/thaumcraft-4-reforged/releases/tag/26.3)

## Сборка из исходников

Установите JDK 25, положите `thaumcraft-4-reforged-1.1.3-26.3.jar` в папку `libs` и запустите `./gradlew build` или `gradlew.bat build` на Windows. Готовый JAR появится в `build/libs`.
